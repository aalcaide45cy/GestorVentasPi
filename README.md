# GestorVentasPi

Gestión de ventas de concesionario (expedientes, clientes, comisiones y puntos) para **Raspberry Pi 4 (ARM64)** y **PC (AMD64)**: Next.js + PostgreSQL en Docker, login con doble factor, copias de seguridad con descarga y Google Drive, y un único instalador.

Estado: **en construcción**. Este repositorio contiene primero la **especificación** (`docs/`) y la **app antigua de referencia** (`referencia/`, solo lectura). El código de la app nueva se escribe desde cero siguiendo `CLAUDE.md`.

- Especificación: `docs/informe/` (por fases) y `docs/INFORME-COMPLETO.md` (todo en uno).
- Reglas de comisiones del propietario: `docs/SISTEMA-DE-COMISIONES.md`.
- Instrucciones para Claude Code: `CLAUDE.md` · Decisiones: `DECISIONES.md` · Avance: `PROGRESO.md`.
